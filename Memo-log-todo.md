# MEMO LOG Todo App Documentation

## Overview
MEMO LOG is a responsive Todo list application inspired by Frontend Mentor designs. Supports light/dark themes, mobile/desktop layouts.

## Features
- Add new todos
- Mark as complete / incomplete
- Delete todos
- Filter: All / Active / Completed
- Clear all completed
- Theme toggle (light/dark)
- Persistent storage (localStorage)
- Responsive design (375px - 1440px)
- Hover and focus states

## Setup & Run
1. Open `index.html` in any modern browser.
2. No build required. Works offline.

## Design Inspiration
Based on Frontend Mentor Todo app:
- Fonts: Josefin Sans (Google Fonts)
- Colors: Specific HSL for light/dark themes (see `style.css`)
- Assets: Icons/backgrounds copied from inspo/

## Keyboard Shortcuts
- Enter to add todo
- Space to toggle complete
- Delete/Backspace to remove

## Customization
Edit `style.css` for colors/fonts, `src/script.js` for logic.

Built with vanilla HTML/CSS/JS.
