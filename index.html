About Memo Log

Memo Log is a simple and elegant todo application designed to help you organize your daily tasks. Built with modern web technologies, it provides a clean interface for managing your activities efficiently.

Features include:

  • Add and delete tasks
  • Mark tasks as completed
  • Filter tasks by status
  • Responsive design for all devices
